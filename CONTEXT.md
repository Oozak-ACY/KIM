# KIM (Keep In Mind)

A mobile memory companion that resurfaces short pieces of knowledge, captured from AI conversations or entered by hand, at the moment they are about to be forgotten. KIM reminds, it does not teach.

## Language

**Card**:
A short, self-contained piece of knowledge the user wants to keep in mind, written to be re-read in seconds, with optional hints.
_Avoid_: Flashcard, note, concept, memory card

**Review**:
One short session where a due Card is shown again to reactivate the memory, lasting 10 seconds to 3 minutes.
_Avoid_: Lesson, study session, reminder

**Nudge**:
The push notification that invites the user to a Review, phrased as a question about the Card's subject.
_Avoid_: Alert, reminder notification

**Quiz mode**:
An optional per-Card setting where the Review asks the user to recall before revealing, then self-grade.
_Avoid_: Test, exam

**Capture**:
The act of creating Cards from an AI assistant conversation through the KIM connector.
_Avoid_: Import, sync, export
